# 云顶之弈 S18 参谋手册（版本 18.6 · 自然之力）

> 用途：AI 参谋模式下的对照手册。你手动操作，我看截图报建议；不写自动脚本、不读写游戏进程内存。
> 数据基准：2026-11-07 前后 18.6 版本第三方大数据；游戏内羁绊/棋子/装备译名与强度以实际对局为准。

---

## 1. 数据源核查结论（"读取内存"的落地边界）

| 数据源 | 本机核查结果 | 结论 |
| --- | --- | --- |
| 客户端本地 API（127.0.0.1 大厅接口） | 腾讯服（WeGame）多个常见端点返回 404，基本不可用；且该接口只覆盖大厅/账号，**不暴露对局内商店、棋盘、经济、血量** | 不可作为对局数据来源 |
| 本地日志 / 存档文件 | `Game\Logs`、`Saved` 下只有客户端 webcache 与性能日志，**没有落地的对局内商店/棋盘/经济数据** | 无可读对局数据 |
| 读取对局进程内存（League of Legends.exe / TFTTencentClient.exe） | 本机运行 ACE 反作弊（AntiCheatExpert）；`ReadProcessMemory` 类手段是外挂常见检测特征，**封号风险高** | **不做**：不读内存、不注入、不做自动脚本 |
| 实际可用的识别方式 | 截图 + 关键区域裁剪（商店 / 经济血条 / 羁绊栏 / 装备栏）+ 游戏自带阵容助手（F2）+ 本地图鉴对照 | 采用 |

**一句话结论**：对局内数据没有合规的直读通道，识别仍以截图为准；提速靠"只裁关键区域 + 对照本手册模板 + 每回合一次性报建议"，而不是读内存。

## 2. 参谋模式工作流

### 2.1 分工
- **你（手动）**：买牌、刷新、升人口、合成装备、拖棋子站位、选择强化符文/赐福。
- **我（参谋）**：每个准备阶段看一次截图，按顺序报：① 买不买、买第几张；② 升不升人口；③ 装备给谁；④ 站位/对位要点；⑤ 要不要转阵容。

### 2.2 每回合观察顺序
1. 顶部：阶段、等级、金币、血量（判断能不能 D 牌 / 升人口）。
2. 左侧羁绊栏：已激活羁绊与缺口。
3. 底部商店：5 张牌的费用、所属体系、有没有体系内牌 / 可追三牌。
4. 右下装备栏：现有散件、可合成装备、主C/主坦装备缺口。

### 2.3 节奏约定
- **战斗阶段**：不操作、不反复截图，等下一准备阶段。
- **准备阶段**：先定阵容方向，再做主C 装备，最后补前排与站位。
- 经济判断：吃利息优先；运营阵容 8 人口前尽量留 50 金；赌狗线在低人口卡利息追三。

### 2.6 显示模式：窗口化对局
- 大厅右上角齿轮 → 设置 → 视频 → 窗口模式选「窗口」或「无边框」，方便同屏看豆包参谋窗口。
- 对局内也可用 `Alt + Enter` 在全屏 / 窗口之间快速切换。
- 参谋时游戏窗口和豆包窗口都留在 main 桌面，不要切到其他虚拟桌面。

### 2.7 抓帧提速方案（本地只读脚本，替代 cu 全屏）
- 脚本：`capture-lol.ps1`（与本手册同目录）。只抓 `League of Legends` 窗口存 JPEG，**不点击、不注入、不读内存**。
- 抓帧方式：**优先 PrintWindow**（直接取窗口自绘内容，不受豆包等上层窗口遮挡）；抽样判为黑屏时自动回退 CopyFromScreen（屏幕合成画面）。
- 实测（1920×1080 桌面，客户端大厅，1600×900 JPEG ~171KB）：
  - cu 全屏：单帧往返 **14.7~15.5 秒**；
  - 本地脚本段（进程启动+PrintWindow+缩放+存盘）：首轮预热 379ms，稳态 **约 0.15 秒**；
  - Read 图片回传往返（含 harness 调度，秒级精度）：**约 6~7 秒/次**；
  - 模型看图理解 + 生成建议：本机无法隔离计时，随建议长短/负载浮动，简短结论通常数秒。
  - 全链路估算：抓帧 ~0.15s + 回传 6~7s + 理解生成数秒；对比旧 cu 15s。
- **待对局验证**：对局内是 DirectX 渲染，PrintWindow 可能返回黑屏；若发生脚本会自动回退 CopyFromScreen，此时需窗口并排、游戏区域可见。
- 用法：跑脚本输出帧图到 `%TEMP%\lol_frame.jpg`，再读图分析；一回合只抓一帧。
- 可调参数：`-Width`（棋子看不清就提到 1920；想更小就降到 1280）。
- 仍压不下去的环节：图片回传 + 模型看图分析 + 生成回复，属固定开销；指令一次说全，战斗阶段不抓帧。

## 3A. 两套主打打法（星神匹配 / 自然之力 · S18 18.6）

### 模式机制要点（先理解，再看阵容）
- **自然仙灵（Wisps）**：每隔一回合出现在商店最右侧槽位，每回合最多买 1 个，提供战斗 / 商店 / 金币经验 / 装备类效果；灵魂莲华体系围绕仙灵联动，买到仙灵会联动出灵魂莲华牌。
- **地形格**：树格给 % 最大生命、岩格给护甲魔抗、水格给法力回复。前排站岩格 / 树格，后排主C 站水格回蓝。
- **选秀（Carousel）回归**：抢带装备的英雄，优先主C 核心小件。
- **大元素使 拉克丝**：场上有 1 个拉克丝时，商店其他拉克丝转成同一羁绊，并为该羁绊 +2 计数，用来补羁绊缺口。

### 两套怎么选（2-1 开局判断）
- 大剑 / 反曲弓多、物理牌多 → **打法 A**；大棒 / 泪滴多、法强牌多 → **打法 B**。

- **装备优先级**：先主C 核心装，再主坦；散件方向 —— 物理：大剑 / 反曲弓 / 拳套；法强：大棒 / 泪滴；前排：腰带 / 锁子甲。
- **选秀**：优先主C 核心小件，其次主坦散件。
- **强化符文**：经济类优先（升级！、生日礼物、史诗刷新、持续刷新），战力类次之；与所选阵容羁绊匹配的纹章 / 专属符文优先。

## 5. 开局判断与变阵原则（2-1 定方向）

1. **看来牌**：前两次商店哪套体系低费牌多，就往哪套靠。
2. **看散件**：大剑 / 反曲多 → 物理（德莱文 / 厄斐琉斯 / 凯尔）；大棒 / 泪滴多 → 法系（莫甘娜 / 拉露恩 / 卡尔玛）；腰带 / 锁子甲多 → 先做前排。
3. **看符文**：经济 > 装备 > 战力；匹配阵容羁绊的专属符文优先。
4. **看同行**：同一主C 被两家以上抢，转重叠前排 / 副C 的变体，不要硬卷。
5. **血量优先**：中期掉血过快就提前 D 牌稳血，不要死憋高人口。
