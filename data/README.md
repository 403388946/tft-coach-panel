# data/

赛季静态词表与图标素材目录。本仓库**不打包**第三方数据与图片。

## 获取来源

- 赛季数据（棋子 / 羁绊 / 装备 / 强化符文 / 图标）参考 [TFT_Spider](https://github.com/Jack0Chan/TFT_Spider) 的官方静态资源归档：
  `seasons/s18/tft_data/tft_processed_data.json`、`seasons/s18/tft_images/`。
- 落地时按需下载到本目录，并在对应文件注明来源快照版本（如 16.18）。

## 使用约定

1. 识别出的名字必须落本目录标准词表归一化，不接受 OCR 自由文本；
2. 图标模板需用真实对局截图实测校准（官方立绘与槽位缩略图有尺寸 / 裁切 / 特效差异）；
3. 版本更新只替换数据包，不改决策逻辑；上线前核对与客户端当前版本一致；
4. 若引入带原许可的素材 / 模型权重，在本目录注明来源与原协议。
